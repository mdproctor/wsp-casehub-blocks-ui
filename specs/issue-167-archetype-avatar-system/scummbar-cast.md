# Scummbar Cast Reference — Game Characters × Archetypes

Design reference for the scummbar pixel art collection. Each sub-archetype maps to 2–3 iconic game characters whose visual signature should inform the pixel art parts. The goal: anyone who grew up playing these games should see the reference and smile.

Not limited to LucasArts — draws from Sierra, Revolution, Telltale, indie pixel art, JRPGs, and any game whose characters work in chunky pixel form.

## Style Guide

- **Grid:** 32×48 logical pixels → 200×240 SVG viewBox (~6×5 per "pixel")
- **Palette:** 8–12 colours per game family. VGA palette feel. Limited but expressive.
- **Technique:** Hard pixel edges, no anti-aliasing. Dithering for gradients/shading. Rectilinear outlines.
- **Detail level:** Higher res than originals — we're at ~200×240 not 320×200, so proportionally more detail per character than the originals had, while keeping the pixel art feel.

## Using This Reference

1. Each sub-archetype's primary reference character defines the "instant read" — the first visual impression
2. Secondary references add variation and depth
3. The visual hook describes WHAT to borrow — specific poses, silhouettes, colour choices
4. Parts from the catalogue (hair, costume, props, etc.) should be drawn to evoke these characters without being direct copies
5. For Gemini's version: share this cast mapping as the design brief alongside the structural SVG
